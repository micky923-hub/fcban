## 시작 순서

1. 폴더 만들기 → 이 패키지 복사 → `git init`
2. Claude Code 실행 → `docs/KICKOFF_PROMPT.md`의 **프롬프트 1** 붙여 넣기
3. 보고 받으면 체크리스트로 확인 → **프롬프트 2**(순서 2부터)
4. 순서 3 전에 **프롬프트 3**으로 건강 데이터 초안 → 출처 대조 후 확정

## 운영자가 준비할 것

- GitHub 저장소(고객 화면 공개 가능, `ops/`는 비공개 분리) + GitHub Pages
- 카카오 디벨로퍼스 JS 앱 키(공유·채널 추가) — 없어도 개발 진행 가능
- 도메인 결정(서브/독립), 뉴스레터 요일·시간(기본 목 09:00)
- 건강 데이터 12세트 출처 대조(Claude Code 초안 → 운영자 확정)

## 이 패키지가 지키는 것

보험사·상품·가입 권유 무언급 / 고객 개인정보 서버 무보관 / 정보성 콘텐츠만 / 발행은 운영자 승인 클릭으로만.
이 네 가지를 어기는 요청은 Claude Code가 거절하도록 `CLAUDE.md`에 적어 두었다.
