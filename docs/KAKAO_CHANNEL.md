# 카카오톡 채널 운영 전략 — 파이낸셜다이어리

2026-11-09 · 블루엠파트너스 · 운영자 반동수

채널: `https://pf.kakao.com/_VxdxkxeX` (일반 채널, 비즈니스 인증 전)
발송 형식과 규칙의 원본은 `docs/SPEC.md` SB-10이다. 이 문서는 그 규칙 위에서 채널을 어떻게 키우고 운영할지를 정리한다. 둘이 다르면 SPEC이 맞다.

---

## 1. 정체성

**"매주 목요일 아침, 생활 속 숫자 정보 한 편"**

- 채널은 정보 미디어의 배달 수단이다. 사이트 절대 규칙(`CLAUDE.md` 1~3: 회사·상품·권유 문구 금지, 개인정보 무보관, 정보성 문장만)이 채널 메시지와 1:1 채팅 답변에도 그대로 적용된다.
- 친구가 남는 이유는 "매주 쓸모 있는 정보가 하나씩 온다"는 기대 하나다. 이 기대를 깨는 메시지(홍보성 문구, 잦은 발송)는 보내지 않는다.

## 2. 발송 규칙 (SPEC SB-10 요약)

| 항목 | 규칙 |
|---|---|
| 주기 | 주 1회, **목요일 09:00** (`docs/SPEC.md` §8-1 기본값). 그 외 정기 발송 없음 |
| 형식 | 와이드 이미지(1200×600) + 제목 + 요약 3줄 + 버튼 2개(`copy.kakao.weeklyButtons`: 글 읽기 / 도구 1개). 버튼 3개 이상 금지 |
| 운영자 한마디 | 별도 텍스트 말풍선, `copy.kakao.operatorNoteMax`(80자) 이내 |
| 요약 3줄 | 글 페이지의 '핵심 요약' 박스와 같은 텍스트 |
| 발송 경로 | `ops/review`에서 승인 → "메시지 복사" → 카카오 채널 관리자센터에서 사람이 직접 발송. 자동 발송 경로는 만들지 않는다(`CLAUDE.md` 4) |
| 문의 | 1:1 채팅이 유일한 창구. 신청 폼 없음 |

## 3. 친구 모으기 — 비용이 들지 않는 순서

1. **기존 고객 1회 안내**: `copy.kakao.oneTimeInvite` 문안을 개인 카톡으로 **한 번만** 보낸다. 다시 권하지 않는다.
2. **사이트 안**: 허브·도구 화면의 "카카오톡 채널 추가" 버튼. 도구가 쓸모 있을수록 친구가 는다.
3. **공유 흐름**: 고객이 도구 화면을 가족에게 공유 → 받은 사람이 사이트 방문 → 채널 추가. 공유 메시지에는 개인 결과값이 들어가지 않는다(SPEC 공통 4).
4. **블루엠 홈페이지**: bluem-partners.com에 파이낸셜 다이어리 소개 카드를 두고, 사이트 링크와 채널 추가 링크를 함께 건다(2026-11-09 기준 아직 링크 없음).
5. **오프라인**: 명함·인쇄 자료에 채널 QR 코드.

유료 광고는 글이 8~12편 쌓여 "이 채널은 이런 글을 보낸다"가 분명해진 뒤에 검토한다.

## 4. 콘텐츠 캘린더

뉴스레터 분류 4개(`data/newsletterRules.json`: 건강 / 상속·증여 / 생활금융 / 운영자)를 돌리고, 글마다 **도구 1개**로 연결한다.

| 주 | 분류 | 연결 도구 | 예시 주제 |
|---|---|---|---|
| 1주 | 건강 | 건강 체크 | 나이대별 국가건강검진 항목 |
| 2주 | 생활금융 | 나이 달력 | 국민연금 수령 개시 나이 확인 |
| 3주 | 상속·증여 | 상속·증여 계산 | 자녀 증여 공제 한도 |
| 4주 | 건강 또는 운영자 | 건강 체크 | 계절 건강 상식 |

시기 주제를 끼워 넣는다.

- 11~12월: 올해 국가건강검진 연말 마감
- 1~2월: 연말정산
- 5월: 종합소득세 신고
- 연중: "올해 내 나이로 달라지는 것"(나이 달력 연결)

**첫 발송 전에 4편을 비축**한다. 바쁜 주에도 목요일 발송이 끊기지 않게 하기 위해서다. 각 글은 `ops/review`의 개요 선승인 → 본문 승인을 거친다.

## 5. 1:1 채팅 응대

- 자동 응답에 답변 시간(예: 평일 ○시~○시)을 적는다.
- 답변은 사이트·글 내용 설명까지만 한다.
- 채팅 내용과 고객 정보는 `ops/` 서버나 외부 AI로 옮기지 않는다(SPEC §5, `CLAUDE.md` 2·5).
- 대화가 개인 사정에 대한 개별 문의로 넘어가면 채널 밖의 별도 경로로 안내하고, 채널은 정보 미디어로 남긴다.

## 6. 운영 전 확인할 것

- **운영자 소속 기관 규정**: 운영자의 소속 기관에 SNS·홍보 활동 규정이 있으면, 정보 채널 운영도 그 대상일 수 있다. 첫 발송 전에 담당 부서에 확인한다.
- **광고성 정보 규칙**: 메시지가 광고성으로 분류되면 정보통신망법상 "(광고)" 표시, 수신거부 안내, 야간(21시~08시) 발송 제한이 붙는다. 목요일 09:00은 야간 제한에 걸리지 않는다. 실제 분류·표시 방식은 채널 관리자센터 발송 화면의 카카오 안내를 따른다.
- **비즈니스 인증**: 친구 수가 늘고 검색 노출·신뢰 표시가 필요해지면 검토한다.

## 7. 성과 확인 (매주 5분)

| 어디서 | 무엇을 |
|---|---|
| 카카오 채널 관리자센터 | 친구 수, 메시지 클릭률, **차단 수** |
| 사이트 | 카카오 유입 방문 수 — SPEC §6의 익명 페이지뷰(참조 채널 kakao)가 아직 없으면 다음 구현 후보 |

- 차단이 늘면 주제·분량을 고친다. 발송 횟수를 늘리지 않는다.
- 클릭이 높은 분류는 비중을 늘린다.

## 8. 시작 순서

1. 운영자 소속 기관에 채널 운영 확인 (§6)
2. 첫 4편 원고 비축 (`ops/review` 개요 → 본문 승인)
3. 기존 고객 1회 안내 발송 (`copy.kakao.oneTimeInvite`)
4. 첫 목요일 09:00 발송
