- 데이터 버전: `0.1-draft` · 상태: **draft** · 생성: `node scripts/health-review.mjs`
- 초안 작성자(Claude Code)는 처음에 출처 원문을 열람하지 않고 썼다.
- **1차 대조 2026-11-09** — Claude Code (1차 대조 — 확정 아님). 두 기관 공식 페이지를 WebFetch 로 읽어 항목별로 비교. 인용문은 페이지 요약 도구를 거쳤으므로 운영자가 원문 페이지에서 한 번 더 확인한다.
- 확정 절차: ① 1차 대조 결과와 아래 원문 페이지를 직접 확인 → ② `assets/healthData.json` 해당 항목 `reviewedAt` 에 날짜(YYYY-MM-DD) → ③ 고위험군 설명은 원문 그대로 붙여 넣고 `verbatim: true` → ④ 전부 끝나면 `_meta.status` 를 `confirmed` → ⑤ `npm run sync` 후 이 스크립트 재실행. 그 전에는 화면에 **초안** 배지가 붙고 배포하지 않는다.
