# 건강 데이터 출처 대조표 (healthData.json)

- 데이터 버전: `0.1-draft` · 상태: **draft** · 생성: `node scripts/health-review.mjs`
- **이 초안은 작성자(Claude Code)가 출처 원문을 직접 열람하지 않고 작성했다.** 모든 항목·주기·연령·검사명이 대조 대상이다.
- 확정 절차: ① 아래 출처 원문과 대조 → ② `assets/healthData.json` 해당 항목 `reviewedAt` 에 날짜(YYYY-MM-DD) → ③ 고위험군 설명은 원문 그대로 붙여 넣고 `verbatim: true` → ④ 전부 끝나면 `_meta.status` 를 `confirmed` → ⑤ `npm run sync` 후 이 스크립트 재실행. 그 전에는 화면에 **초안** 배지가 붙고 배포하지 않는다.
